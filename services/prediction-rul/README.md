# Service PrédictionRUL

## Description

Service Python/FastAPI avec modèles ML/DL custom pour l'estimation de la Remaining Useful Life (RUL).

## Fonctionnalités

- Modèles LSTM/GRU/TCN custom (PyTorch)
- XGBoost (baseline)
- Transfer Learning depuis NASA C-MAPSS
- Calibration et intervalles de confiance
- MLflow tracking

## Technologies

- Python/FastAPI
- PyTorch (modèles custom)
- XGBoost
- MLflow
