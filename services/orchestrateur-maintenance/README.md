# Service OrchestrateurMaintenance

## Description

Service Spring Boot responsable de la planification optimisée des interventions de maintenance.

## Fonctionnalités

- Moteur de règles Drools
- Optimisation planning avec OR-Tools
- Génération d'ordres de travail
- Intégration CMMS/ERP
- Gestion des contraintes (sécurité, SLA, inventaire)

## Technologies

- Spring Boot
- Drools
- OR-Tools
- PostgreSQL
