# Service DashboardUsine

## Description

Interface web temps-réel pour la visualisation de l'état des équipements, alertes, RUL et planification.

## Fonctionnalités

- Dashboard React.js temps-réel
- Visualisations Plotly
- Intégration Grafana
- WebSockets pour updates live
- Cartographie GIS (PostGIS)
- Export PDF/CSV
- KPI (MTBF, MTTR, OEE)

## Technologies

- React.js
- FastAPI (backend)
- WebSockets
- Plotly, Grafana
- PostGIS
